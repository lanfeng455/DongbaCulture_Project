# Forest Crossing — 最小可玩原型

Unity 6000.3.0b1 / Windows。所有新增源码位于本目录；原 SampleScene、输入配置和 URP 配置保持不变。

## 运行

双击 `Builds/ForestPrototype/ForestPrototype.exe`，或打开本目录 `ForestPrototype.unity` 后点击 Play。
菜单 Dongba Prototype / Build Windows Player 可重新构建独立程序，不改变原 Build Settings。

A/D 或左右箭头移动并改变朝向；Space/W/上箭头跳跃；J/Enter 使用斧字形挥击；R 重置。河流范围 8–11，靠近岸边再跳；落水自动回到左岸。

采用横版即时战斗：接触动物不锁定角色，攻击的起手、命中、收招期间始终可以移动和跳跃；胜利后也可继续走动。斧字形围绕人物手部平滑完成抬起和下劈，并与人物朝向、冲刺、墨点和敌人击退共用出招时锁定的方向。斧刃外轮廓本身就是攻击碰撞体，它与显示使用相同的握持点、尺寸、镜像和旋转变换；只有下劈中段的斧刃轮廓与动物碰撞区域实际相交才会命中。旧版红色直线攻击提示和独立的前方距离判定均已移除。每次挥击持续 0.32 秒，每次最多造成一次伤害，鸡三次命中后消失。

鸡现在会在右岸小范围巡逻；玩家跳过河并进入约 3.8 世界单位的警戒范围后，鸡会转向、追近，并在近距离进行带 0.28 秒前摇的短促啄击。玩家拥有三格生命，受击后会变色闪烁、产生墨点、轻微震屏和击退，并获得 0.9 秒无敌时间；生命清空后短暂停顿并返回左岸，生命恢复为三格。生命 UI 不使用矩形面板或英文名称：玩家左上角显示一个小人物字形和三道不规则暗红墨痕，动物生命只在交战时以浮在动物上方的墨痕出现，失去的生命变为低对比度残墨。战斗仍然不切换场景。

## 素材状态 / 许可

当前运行版采用用户确认的预览 09 作为场景美术基准：纸张环境底图保留太阳、云、天、树木、植物、盆状地表符号、浅褐地下土字、河岸和灰蓝水字；人物与鸡从确认稿拆为独立透明字形，以便移动和战斗。纸张仅作为背景，地形判定仍由独立碰撞逻辑负责。冲击音为程序合成。

背景音乐 `林间墨风 / Forest Ink Wind` 是项目内程序合成的原创占位曲，参考资料中记录的拨弦、口弦、笛与木质打击乐器类别来建立音色层次，没有使用或转录网络试听、商业唱片或第三方采样。它只表示待确认的音乐方向，不是纳西传统曲目或经文化专家核验的复原演奏。完整来源状态与生成方式记录于 `Verification/music-source.md`，正式版本仍应委约或取得明确授权的纳西音乐。

当前只应用局部环境动画测试：三棵高树、三株独立植物、全部十个水字和一朵云。树、草和水共享 `MasterPeriod = 2.2` 秒及统一的 `MasterWindPhase`，不再随机生成独立频率。树只保留 0.12—0.30 秒响应差；草的主运动为 70% 主相位，并叠加 30% 二次谐波。水字保持原始三排位置，以 `sin(masterPhase - columnIndex × 0.35 + rowIndex × 0.18)` 产生从左到右的空间延迟，岸边幅度约 ±2.7—3 像素、中央约 ±4—4.8 像素。阵风只统一放大树、草和水的幅度，不改变频率或相位关系。云继续独立匀速漂移。地面、土层、河道墨晕、岸线、纸张、太阳和 UI 保持静止。

`ForestPrototype` 暴露 `WindStrength`（默认 0.85）、树／草顶部位移、云速度、水流速度、水面浮动和待机呼吸参数。高树顶部普通微风约 6—12 个最终屏幕像素、阵风峰值约 14—22 像素；草木普通约 4—8 像素、阵风约 8—14 像素。角色有约 0.9% 的纵向呼吸，鸡会偶尔抬头并轻移；战斗命中会暂停环境风动 0.2 秒，再以冲击风恢复。所有随机周期、相位和幅度都由固定种子在启动时生成，不会逐帧跳变。

最终 Windows 构建在本机实测平均 59.62 FPS，环境动画平均每秒更新 59.62 次；`Application.targetFrameRate` 为 60，`QualitySettings.vSyncCount` 为 0。环境运动全部在 `Update` 中按 `Time.unscaledDeltaTime` 连续推进，不使用低频 Coroutine、整数像素步进或离散切帧。树梢红点、位移数值和 FPS 面板只在 `--motion-debug` 模式显示，正常启动默认隐藏。

这些图形均是方向预览素材，并非已经完成权威释义和授权核验的正式东巴字形。人物参考、鸡参考、盆状地表参考以及标注为“土”的参考均由用户提供；字义、原始出处与许可待核实。人物保持用户确认的圆头与“大”字式身体结构，并加入暗红头带、腰带结和一笔衣襟作为身份服饰装饰；这些新增笔画不作为东巴字释义，也不改变手脚锚点。按用户要求已恢复最初服饰版本，头带、腰带和人物属于同一张完整字形，会随人物整体变换，不再使用独立飘带分层。斧素材参考在线东巴字表中完整标注为“斧、铁”的一形多义条目，按用户确认的结构重新绘制为透明深褐色手绘素材；该网页尚未找到明确的素材复用许可，因此当前只用于概念 Demo，不能把它单独宣称为已权威核实的“斧”。树木、植物、天空和水的视觉沿用用户确认稿，也暂不宣称具备权威字义。正式发布前必须逐项替换或补全可靠字典／馆藏／出版物出处与明确许可记录，不能依据当前画面自行解释字义。

## 验证

独立程序带 `--prototype-test` 参数执行真实运行时冒烟验证：落水复位、跳河、接触不锁移动、远距离/背向/高空挥空、出招中移动与跳跃、斧刃碰撞、单次挥击最多一次伤害、三击击败、动物巡逻与警戒攻击、玩家扣血与受击无敌、胜利后移动和重置；输出到程序目录 verification.txt，并截图 forest.png / battle.png / victory.png。此验证使用与键盘相同的 Tick/Attack 逻辑，但不模拟操作系统键盘输入。

最小范围仅包含移动、跳跃、河流、即时近战、三次命中击败动物和重玩。不含装备、背包、等级或存档。


## 体验模式

体验模式直接扩展现有森林场景。E 键在植物附近执行种植或照料，在动物附近投放食物；J / Enter 的斧刃除动物外也能命中三棵独立动态树。照料行为与破坏行为共同推动森林进入平衡、繁盛或衰败状态：繁盛时植物完整生长，被持续喂养的动物停止攻击并出现新个体；衰败时环境色调、音乐和风水动态逐渐减弱。所有新增植物仍复用当前已在画面中的植物素材，食物只用普通墨点表示，没有添加或编造新的东巴字形。
