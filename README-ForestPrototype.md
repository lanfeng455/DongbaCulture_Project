# 东巴森林体验原型

使用 Unity Hub 打开这个仓库，团队项目版本为 6000.3.12f1。
原型源项目使用 6000.3.0b1；本次保留团队的版本、插件和项目设置。

打开 Assets/DongbaPrototype/ForestPrototype.unity，然后点击 Play。
也可以通过菜单 Dongba Prototype > Open Prototype Scene 打开。
A/D 或方向键移动，Space 跳跃，J/Enter 攻击，E 培育或喂食，R 重新开始。

程序、美术和音乐位于 Assets/DongbaPrototype，包含原有 .meta 文件。
本次导入未覆盖团队已有场景，原型也没有设为默认启动场景。
菜单 Dongba Prototype > Build Windows Player 可以构建 Windows 程序。
