# 素材目录与替换说明

更新：2026-10-27。本文以当前斜俯视森林 `ObliqueForest.unity` 为准；旧横版资源仍保留，但不等于当前场景在使用。资源路径均相对仓库根目录。

## 先看素材来源边界

- `Assets/DongbaPrototype/Resources/DictionaryArt/catalog.json` 是字典裁切资源的键名、标签、裁切来源和 SHA-256 索引；`素材来源.csv` 记录原条目 OCR 与页码。OCR 和裁切标签是整理线索，不应单独当作权威释义。
- `Assets/DongbaPrototype/Resources/DictionaryArt/README.txt` 记录了这批素材的整理方式和限制。动物素材中有些是头部字形，游戏没有替它们补画身体；短横线、三短竖线草只是场景装饰，不代表已核实的东巴字义。
- 目前不能把项目内每一张游戏图形都称为“原始东巴字”。请区分：字典裁切原图、基于字形拆层/清理的游戏资源、普通道具或程序生成效果。需要正式对外释义或确认授权时，仍需回到原书版本、页码和授权信息核实。
- 不要直接覆盖字典原图。替换派生资源时保留尺寸比例、透明通道和脚底锚点；如果资源由代码按命名规则加载，也要同步维护文件名与 `.meta`。

## 替换前快速检查

1. 先确认资源属于当前场景、旧横版、素材原图还是程序生成效果。
2. 查看 `catalog.json`、`素材来源.csv` 和对应 ArtSources 文档，记录来源页码、授权状态与修改方式；不确定就标“待核实”。
3. 对玩家、动物、植物、武器和花路保留透明背景与原长宽比；确认脚底、手持点及碰撞位置。
4. 检查 Unity 导入设置和 `.meta` 是否保留；不要只复制 PNG 到仓库外，导致 Unity GUID 改变或引用丢失。
5. 替换后在 `ObliqueForest.unity` 的实际游玩镜头下检查层级、遮挡、尺寸与交互，不以单独放大的素材图代替实机判断。
