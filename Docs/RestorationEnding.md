# 恢复森林结尾（第一版）

剧情按用户本次设定：救出父亲后，父亲遇难；高勒趣独自回到曾经砍伐的林地，重新种植、照料，逐渐恢复森林。这是游戏改编方案，不将新增台词当成原经文引文，也未加入祭祀、招魂或葬礼仪式。

目前可单独启动 Builds/Current/Start-Restoration.bat，从一片已经砍伐、动物稀少的测试林地开始。先停留观察，回车逐句推进三句简短台词，再自由行动。E补种/培育/喂养，WASD移动，Space跳跃，J攻击，R从开头重开，Esc退出。

正式入口 BeginRestorationEnding() 保留实际地图中之前被砍的树、生态分数和动物状态，不重建森林。位置选在离原出生点最近的旧树桩旁。独立预览另行模拟开场伤害，8棵附近树和2只动物的伤害都走现有计分；这只用于测试启动，不在正式故事入口执行。预览的动物在开场黑幕下放到镜头外，实际故事入口仍使用原迁出逻辑，不删除眼前动物。

现有规则保留：补种+1、培育每棵一次、幼兽长成成年时+1、杀动物-2；不另建一套生态分数。该章补种的旧树桩会从小树苗继续长大，叶片、颜色、花路沿用已有生态反馈。站在树桩上补种时会挪到旁边可走的位置，避免被新树根卡住。

动物优先通过原迁出/返回系统恢复。若至少两棵重种树长到85%、生态已回到非负而附近没有足够动物，优先选择已迁出的个体，确实没有可返回个体时才补充新成体，最多引导两只，间隔至少12秒，先从林地寻找连通的镜头外入口，再沿已有寻路回到林地；不复活已经杀死的个体，不增加生态分数。喂养、成长、繁殖、繁盛跟随仍按原规则。

至少重种两棵旧树桩、长到85%，并达到现有繁盛阈值与颜色过渡后，播放一句结尾，继续保留自由活动。ForestRestorationCompleted事件供后续接片尾/菜单。本轮不制作新的死亡动画和仪式素材。

与组员关卡的接法：最终救父/父亲遇难演出结束时，调用活动的 ReelPortalHost.ReturnToForestForRestoration()，返回森林后进入本章；若协调器已经恢复了森林场景，直接调用 ObliqueForest.BeginRestorationEnding()。普通PuzzleCompleted事件仍只返回卷轴，不自动认定父亲已获救。正式救父终点事件尚待组员绑定，当前演出是独立可测的结尾。

验证使用本机Unity6000.3.0b1兼容工程，团队6000.3.12f1未安装。音效继续使用现有纳西语录音挂钩，缺少录音时不会合成或杜撰发音。
