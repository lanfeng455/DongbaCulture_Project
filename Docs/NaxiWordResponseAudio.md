# 自然回应语音：接入说明

更新：2026-10-29。

## 触发方式

当前斜俯视原型会在一次照料动作**成功发生的同一帧**播放对应录音，声音从被照料的对象位置发出：

- 补种树桩：播放树的词音。
- 成功培育树、长出周边植物：播放树的词音。
- 喂养动物并使其成长，或成功生出幼兽：播放对应动物的词音。
- 冷却中、没有可用空间、种植失败等没有产生变化的操作不播放。

音量由 `ObliqueForest` 组件的 `NaxiWordVoiceVolume` 调整；声音采用场景位置衰减。脚本从 `Resources/Audio/NaxiWords/` 加载文件，文件名不带扩展名传给 `Resources.Load`。

## 录音文件名

| 文件名 | 对应对象 |
| --- | --- |
| `tree.wav` | 树 |
| `animal_00.wav` | 鸭 |
| `animal_01.wav` | 野鸭 |
| `animal_02.wav` | 鹅 |
| `animal_03.wav` | 箐鸡 |
| `animal_04.wav` | 猫 |
| `animal_05.wav` | 兔子 |
| `animal_06.wav` | 狐狸 |
| `animal_07.wav` | 野猫 |
| `animal_08.wav` | 驴子 |
| `animal_09.wav` | 猪 |
| `animal_10.wav` | 牛犊 |
| `animal_11.wav` | 松鼠 |

只先提供树和鸡的录音也可以；其余文件缺失时对应对象静音，不影响交互。当前仓库只有背景音乐，没有这些纳西语词音，因此语音钩子已接好，但尚无可听见的词音。缺少录音时，运行日志会按对象键提示一次；不会用合成音或臆造发音代替。

## 录音资料记录

新增录音时，请一并记录词义、所用纳西语方言/地区、说话者或录音来源、授权许可和核对人。东巴字形的释义不能直接推定纳西语发音。音频确认后放入上述 `Resources` 路径即可，代码会自动读取。
