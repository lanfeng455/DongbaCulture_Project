双版本开发说明（2026-11-24）

PC 与 PICO VR/MR 在同一工程维护，不复制两套森林玩法。
PC 继续使用现有入口、镜头、键鼠操作与完整卷轴/解谜流程；MR 使用 Assets/PicoMR/DongbaPicoMR.unity 的放置、追踪相机与手柄入口。
森林生态、动物种类、培育/成长、人物素材和剧情数据共用。今后的共用功能修改需同时检查键鼠和手柄路径。
MR 目前完成森林入口与交互接入；卷轴、解谜全流程的头显适配尚未完成，不能据此称为与 PC 全流程等价。

本轮完成
1. MR 不再把字幕挂在旁侧控制面板。沿用自己的纸条、人物头像、中文/英文台词与逐句推进，在视野下部以 1.1 米深度显示；提示使用手柄 A。靠近桌面时字幕不会被树木或纸面截断。桌面 PC 字幕位置与键盘提示不变。
2. 森林动物交互卡显示字典素材索引中的具体名称；幼兽附加成长阶段，成长后恢复种类名称。PC 和 MR 使用同一函数。只有接近实际交互对象时显示，不在全场叠加浮动标签。
3. 主角和父亲增加短促的纸片转身，保留脚底位置，遇到连续反向输入不会突然还原宽度。攻击直接完成转身并锁定本次方向，避免图形、手部与斧头判定分离。已有卷轴缩放与过场仍是各自的原系统。
4. 修正手柄同帧反向摇杆+扳机时可能沿上一方向出手的问题。

动物名称数据
Assets/DongbaPrototype/Resources/DictionaryArt/catalog.json：label 是原素材索引释义；labelEn 是游戏界面的英文显示名。原 PNG、裁切框和来源哈希未改。英文界面名称不是对原经文的正式翻译；箐鸡暂用 Qingji bird，未自行断言具体生物学物种。
当前 12 种：鸭、野鸭、鹅、箐鸡、猫、兔子、狐狸、野猫、驴子、猪、牛犊、松鼠。
这批当前森林素材没有马和狗，不能将驴或野猫改标为它们。后续可从全本库核对并接入新条目。

本地资料库保留全本 631 页、631 张页图、全文及 2101 个自动裁切候选。它不是仅有三大类，也不是所有候选都已逐字核实；OCR 错字、漏裁或一图多字仍可能存在。
Unity 的 DictionaryArt 是筛选后的场景库：9 个植物条目、12 个动物条目、2 个地面装饰；此外 ApprovedArt 和组员素材目录还存有人物、刀、斧、房屋、火塘、日月、署、卷轴与谜题图形。两个地面装饰不是字典释义条目。
完整资料库不随 Git 下载，运行游戏无需它。队友需要检索全部字形时需另行复制完整库；实际使用的素材必须进入 Assets 并保留 .meta。

验证入口
PC：ForestPrototype.exe --character-presentation-check；含真实键盘输入、喂养后继承名称、语言切换、快速反向与攻击锚点检查，；额外带 --character-motion-preview 时生成正常视角动画帧。
MR：编辑器 DongbaXR.Editor.DongbaPicoIntegrationCheck.Run，命令行带 --pico-integration-check；模拟表面放置、手柄、头部转动与重新放置。
相关输出位于 Verification/character-presentation 和 Verification/pico-integration；不进入发布包或 Git。
主工程仍为 Unity 6000.3.12f1；本机现有 6000.3.0b1 兼容验证工作目录仅用于测试，不将降级配置写回主工程。
本机无 PICO 头显和 Android 构建模块，无法交付经过头显验证的 APK，空间舒适度、双眼显示和真实追踪需设备端继续验证。
