# UI 第一版整理（2026-11-06）

只调整当前森林原型的UI呈现，未改变生态计分、对象尺寸、地图、角色动作或剧情触发条件。

- 左上收为DONGBA、当前模式和五个生命墨点；受损格变浅，替代原来的竖线字符串。
- 顶部删除整行按键和开发用阈值/距离文本。剧情目标用短句纸签，开场和等待独白期间隐藏重复目标。
- H展开/关闭操作说明；初期保留简短基础键提示。对话和锁定剧情时隐藏无效交互提示。
- 右下交互卡统一对象名、E照料/喂养与J挥斧；已培育的树明确显示Tended once，树桩只提示补种。
- 父亲对话分说话人、正文、页码与继续提示；等待/醒悟独白、事件反馈和大野猪标记使用同一纸色与墨色体系。
- 纸签边缘和生命墨点是普通UI装饰，不是新增东巴字。原字形素材未更改。字体正文沿用Unity内置，标题优先使用系统Georgia，不可用时回退内置字体，不额外分发字体文件。

实现新增ObliqueForest.QuietUI.cs；原Layout/FatherIntro/FatherAI/StoryJourney/AfterCapture与主Update仅接入UI工厂、文案和H键。UI装饰纹理仅启动时生成一次；无逐帧重建图片或材质。
