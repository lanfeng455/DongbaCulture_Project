# 繁盛动物绕行

复用原有繁盛阈值与2秒状态防抖、附近动物参与资格、六只参与上限。按距离吸引动物，前三只参与者在玩家周围约2.8世界单位处绕行，约13秒一圈；额外参与者在较外侧跟随，最多三只。绕行组保持稳定，避免每帧按距离重新排序造成换位；死亡、受攻击、离开有效范围或退出繁盛后释放名额。原有外围跟随轮换保留。

目标随玩家平移；空地上逐帧追随连续圆周目标，受阻时采用已有寻路。亲近动物以树根、房屋、河流、动物间距为地面通行约束，允许按照场景深度关系从树冠下方经过，不再将整片直立树冠当作实心墙。房屋范围加入现有寻路图，避免路径规划穿过房屋后卡住。狭窄或有障碍的位置可能暂停绕行，不强行穿过障碍。不改变普通动物、生态计分、素材和布局。

Windows验证参数 --animal-circle-check。测试在原地图西侧林地达到繁盛，并额外放入三只附近成年动物作为测试夹具，检查三只绕行、外围跟随、实际移动、攻击中止和退出繁盛。测试添加动物仅在此命令下执行，不影响普通启动。实机结果在Verification/animal-circle；构建使用本机Unity6000.3.0b1，未替代团队6000.3.12f1验证。
